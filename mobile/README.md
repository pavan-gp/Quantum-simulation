# Mobile Secure Command App Mock

This is a companion mobile application designed in **React Native** + **Expo** for the **Post-Quantum Secure Military Communication Portal**.

## Key Security Features Built-in:
- **Biometric FaceID / Fingerprint Login check**: Ensures unauthorized local device hijackings are locked out.
- **FastAPI Secure TLS Channel Handshake**: Synchronizes message lists dynamically from the backend nodes.
- **Delivery verification badges**: Validates blockchain seals directly on hand-held mobile nodes.

## Commands:
Run the following inside this directory to build/test:
1. `npm install`
2. `npm run start` (or `npx expo start`)
3. Open in iOS simulator or Android emulator.
